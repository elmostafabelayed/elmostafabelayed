## 📂 Featured Projects

### 💼 Jobsy — Freelance Marketplace Platform
- **Description:** Full-Stack freelance marketplace built during a one-month internship at UNiCREATIVE.
- **Features:** User/project/proposal management, messaging, reviews, role-based routing (Client/Freelancer/Admin), RESTful API, responsive UI.
- **Tech Stack:** React, Redux Toolkit, Laravel 10, Sanctum Auth, MySQL, Bootstrap, Git/GitHub

### 💧 Water Leak Guardian
